# Kế hoạch Triển khai Chi tiết Giai đoạn 1: Bố cục IDE + Explorer + Xem File Chỉ Đọc

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Triển khai Giai đoạn 1 của Minimalist Embedded IDE cho Agent Company: Bố cục 4 vùng chuẩn màn hình 1366px (Activity bar, Sidebar Explorer lazy-load depth=1, Editor area với Pinned Tab Văn phòng pixel, Bottom panel cho Luồng việc & Nhật ký giữ nguyên bộ chọn câu hỏi, Chat Manager bên phải giữ nguyên approval và queue), backend an toàn tuyệt đối với `src/ide-fs.ts` (jail workspace, symlink escape check qua ancestor realpath, chặn file bí mật theo `guard.ts`, phát hiện binary, giới hạn 2MB), file viewer chỉ đọc có số dòng và cú pháp Prism (tự động tắt khi >500 dòng hoặc >200KB), hỗ trợ Light/Dark theme.

**Architecture:**
- **Backend (`src/ide-fs.ts`, `src/server.ts`):** Module FS an toàn với `assertSafeWorkspacePath` (chặn traversal `../`, duyệt đệ quy tìm realpath của ancestor tồn tại để phát hiện symlink thoát khỏi sandbox, tích hợp bộ lọc secrets từ `src/guard.ts`), `listWorkspaceTree` (lazy load `depth=1`, lọc `.git`, `node_modules`, `.company`), `readWorkspaceFile` (phát hiện byte null, hash SHA-256, giới hạn 2MB).
- **HTTP Endpoints (`src/server.ts`):** `GET /workspaces/:id/tree?path=.&depth=1`, `GET /workspaces/:id/files?path=...`.
- **Frontend Layout (`ui/index.html`, `ui/styles.css`, `ui/js/app.js`):**
  - **Activity Bar (48px):** Icons chuyển đổi Explorer (`Ctrl+B`), Bottom Panel (`Ctrl+J`), Chat (`Ctrl+Alt+B`), Cài đặt, Kho role, Dark/Light theme.
  - **Sidebar Explorer (240px, resizable):** Cây thư mục lazy load, nhấp mở/đóng thư mục, nhấp file mở tab editor, ẩn các thư mục build/dependency.
  - **Editor Tabs & Central Area:** Tab đầu tiên ghim cố định `🏢 Văn phòng 📌` (chứa toàn bộ canvas 2D pixel office), các tab tiếp theo là file code mở từ Explorer.
  - **Bottom Panel (resizable, toggle `Ctrl+J`):** Chứa 2 tab `Luồng việc` và `Nhật ký`, giữ nguyên 100% tính năng bộ chọn câu hỏi và bộ lọc.
  - **Chat Manager (340px, toggle `Ctrl+Alt+B`):** Khung chat Manager, giữ nguyên hàng đợi tin nhắn ("Đang chờ (#2)" + nút "Bỏ"), dải trạng thái ("N tin nhắn đang chờ"), thẻ duyệt approval.
  - **File Viewer (Read-only):** Đánh số dòng, highlight cú pháp PrismJS (vendor 1 file tại `ui/vendor/prism.js`, cập nhật `THIRD_PARTY_NOTICES.md`), tự tắt highlight khi file >500 dòng hoặc >200KB, cảnh báo file nhị phân/bí mật/quá cỡ.
- **Spec Updates (`docs/superpowers/specs/2026-10-22-minimalist-embedded-ide.md`):** Cập nhật 4 điều chỉnh theo chỉ đạo của User (bảng phím tắt, editor textarea phủ `<pre>`, diff shadow backup duy nhất, vendor rule).

**Tech Stack:** Node.js >= 22.19, TypeScript (erasable syntax), `node:test`, `node:assert/strict`, Vanilla HTML5/CSS3/ESM, PrismJS (MIT, vendored).

## Review Focus & Failure Modes
1. **Bảo mật Path Jail & Symlink Escape:**
   - Kẻ tấn công tạo symlink `symlink -> /etc` hoặc `symlink -> C:/Users` rồi mở file `symlink/passwd` hoặc `symlink/nonexistent.txt`.
   - Hàm `assertSafeWorkspacePath` phải lùi dần từ target path lên ancestor đầu tiên đang tồn tại trên đĩa, lấy `realpathSync(ancestor)` và kiểm tra tiền tố so với `realpathSync(wsRoot)`.
2. **Không làm mất tính năng chọn câu hỏi (Question Selector):**
   - Bộ chọn câu hỏi (`#flow-question` và `#log-question`) trong tab Luồng việc và Nhật ký phải tiếp tục hoạt động hoàn hảo khi di dời vào Bottom Panel, bao gồm đồng bộ hai chiều và live update.
3. **Bảo toàn các tính năng cốt lõi:**
   - Workspace dropdown menu, Run selector / replay mode, Chat feed, Approvals, Queue persistence ("Đang chờ (#2)" & cancel button) phải hoạt động 100% bình thường.
4. **Hiệu năng File Viewer:**
   - File lớn (> 500 dòng hoặc > 200KB) phải tự động tắt highlight, render dạng plain text trong `<pre><code>` để không làm đơ trình duyệt. File > 2MB bị từ chối 413 ở server.
5. **Độ ổn định ở màn hình 1366px:**
   - Chiều rộng các cột phân chia hợp lý (Activity bar 48px, Explorer 240px, Editor co giãn ~738px, Chat 340px). Khi đóng Explorer hoặc Chat, Editor tự động dãn rộng tối đa.
