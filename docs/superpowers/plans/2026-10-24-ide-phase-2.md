# Kế hoạch Triển khai Chi tiết Giai đoạn 2: Sửa và Lưu File trong Editor (Minimalist Embedded IDE)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Triển khai Giai đoạn 2 của Minimalist Embedded IDE: Cho phép sửa và lưu file trực tiếp trong Editor với kỹ thuật "textarea trong suốt phủ lên `<pre>` tô màu", hỗ trợ gõ tiếng Việt mượt mà (Telex/Unikey/VNI không nuốt chữ, không mất dấu), phím Tab chèn 2 dấu cách, undo/redo gốc; lưu file atomic (file tạm + rename), bảo toàn kiểu xuống dòng (CRLF/LF) và UTF-8; phát hiện xung đột 409 khi AI/tiến trình khác sửa file; giải quyết xung đột với 3 lựa chọn (Xem khác biệt, Nạp lại, Ghi đè); tạo file mới an toàn từ Explorer chống path traversal và symlink escape; tích hợp SSE phát hiện file bị AI sửa để tự nạp lại hoặc cảnh báo ngay.

**Architecture:**
- **Backend (`src/ide-fs.ts`, `src/server.ts`):**
  - `saveWorkspaceFile(wsPath, subpath, content, options: { expectedSha256?, force? })`: Đọc sha256 hiện tại, nếu lệch và không có `force: true` thì ném lỗi `HttpError(409, "conflict", { diskContent, diskSha256, diskMtime })`. Ghi atomic thông qua file tạm ẩn cùng thư mục `.${name}.tmp.${ts}.${rand}` rồi `fs.rename`. Tự động nhận diện CRLF (`\r\n`) của file gốc để bảo toàn định dạng xuống dòng. Bảo toàn UTF-8. Chặn tuyệt đối file bí mật và file ngoài workspace root bằng `assertSafeWorkspacePath`.
  - `createWorkspaceFile(wsPath, subpath, content = "")`: Tạo file mới, tạo thư mục cha nếu chưa có (`mkdir({ recursive: true })`), kiểm tra an toàn bằng `assertSafeWorkspacePath` (chặn traversal `../`, symlink escape, file bí mật `.env*`, `.company/`).
  - Endpoints: `PUT /workspaces/:id/files` (sửa/lưu file) và `POST /workspaces/:id/files` (tạo file mới).
- **Frontend UI (`ui/js/ide/editor.js`, `ui/js/ide/tree.js`, `ui/js/app.js`, `ui/styles.css`):**
  - **Trình soạn thảo hai lớp (Two-layer Editor):** `<textarea>` trong suốt (`color: transparent`, `caret-color: var(--ink)`) nằm trên, đón nhận toàn bộ sự kiện gõ phím, IME composition tiếng Việt, native undo `Ctrl+Z` / `Ctrl+Y`, Tab (2 spaces). Thẻ `<pre><code>` nằm dưới hiển thị syntax highlight từ PrismJS. Gutter đánh số dòng đồng bộ scroll với textarea.
  - **Tối ưu file lớn:** Khi file > 500 dòng hoặc > 200KB, tắt lớp `<pre>` tô màu cú pháp, textarea hiển thị chữ bình thường (`color: var(--ink)`) đảm bảo tốc độ phản hồi 60fps.
  - **Trạng thái Dirty & Tab Safety:** Dấu chấm tròn `●` trên tab khi nội dung chưa lưu. Hỏi xác nhận khi đóng tab hoặc chuyển workspace mà còn file chưa lưu.
  - **Phím tắt Ctrl+S & Concurrency 409:** Bấm `Ctrl+S` gửi `PUT /files` kèm `expectedSha256`. Nếu gặp 409, mở Modal giải quyết xung đột với 3 lựa chọn: Xem khác biệt (Simple Inline Diff), Nạp lại từ đĩa, Ghi đè bản hiện tại (`force: true`).
  - **Tạo file mới trong Explorer:** Nút `+` trên header Explorer, mở modal nhập tên file (ví dụ `src/helpers.js`), gọi `POST /files`, refresh cây Explorer và mở ngay tab file mới.
  - **SSE Live Conflict Detection:** Bắt sự kiện `tool_call` (`write`, `edit`). Nếu tab đang mở chưa sửa: tự động nạp lại nội dung mới nhất. Nếu tab đang có sửa đổi chưa lưu: hiển thị banner cảnh báo xung đột ngay lập tức.

**Tech Stack:** Node.js >= 22.19, TypeScript (erasable syntax), `node:test`, `node:assert/strict`, Vanilla HTML5/CSS3/ESM, PrismJS (MIT, vendored).

## Review Focus & Failure Modes
1. **Gõ tiếng Việt Telex/Unikey không bị lỗi ký tự:**
   - Khi gõ bộ gõ có dấu trên textarea, các sự kiện `compositionstart`, `compositionupdate`, `compositionend` diễn ra. Việc tô màu cú pháp chỉ kích hoạt sau `compositionend` hoặc trên thẻ `<pre>` ngầm, không can thiệp vào DOM selection hay value của textarea trong lúc composition đang diễn ra.
2. **Ghi Atomic & Bảo toàn định dạng xuống dòng (CRLF/LF):**
   - File tạm phải được tạo cùng thư mục với file đích để đảm bảo cùng phân vùng ổ đĩa (same filesystem volume), giúp lệnh rename là atomic. Nếu file gốc sử dụng CRLF (`\r\n`), nội dung mới lưu xuống đĩa phải duy trì `\r\n`, không bị biến thành `\n`.
3. **Bảo mật khi tạo file mới:**
   - Kẻ tấn công tạo file với tên `../../etc/evil.sh` hoặc tạo file trong symlink trỏ ra ngoài. `createWorkspaceFile` phải sử dụng `assertSafeWorkspacePath` duyệt ancestor realpath để chặn đứng trước khi gọi `mkdir` hoặc `writeFile`.
4. **Phát hiện xung đột 409 chính xác:**
   - Khi `expectedSha256` không khớp hash hiện tại trên đĩa, server phải từ chối ghi và trả về `409 Conflict` kèm nội dung mới nhất trên đĩa (`diskContent`). Chỉ cho phép ghi đè khi client gửi cờ `force: true`.
5. **Đồng bộ cuộn và số dòng:**
   - Textarea và pre phải có cùng chính xác `font-family`, `font-size`, `line-height`, `letter-spacing`, `padding`, `border`. Mọi thao tác cuộn trên textarea phải cập nhật tức thì `scrollTop` và `scrollLeft` của pre và gutter.

## Tiêu chí Nghiệm thu (DoD - Definition of Done)
1. **Editor hai lớp hoạt động hoàn hảo**:
   - Gõ tiếng Việt Telex/Unikey/VNI không bị nhảy ký tự hay mất dấu nhờ bắt sự kiện composition.
   - Tab chèn đúng 2 khoảng trắng.
   - `Ctrl+Z` / `Ctrl+Y` sử dụng native undo history của textarea.
   - Thẻ `<pre>` tô màu PrismJS và gutter số dòng cuộn đồng bộ 100% với textarea.
   - File > 500 dòng hoặc > 200KB tự động tắt tô màu, sửa dạng plain text siêu mượt.
2. **Lưu file an toàn & Quản lý xung đột (409)**:
   - Ghi file atomic (file tạm + rename), bảo toàn CRLF (`\r\n`) và UTF-8.
   - Khi hash lệch: Trả về HTTP 409 Conflict kèm `diskContent`.
   - Dialog giải quyết xung đột cung cấp đủ 3 lựa chọn: Xem khác biệt, Nạp lại, Ghi đè (`force: true`).
3. **Bảo vệ dữ liệu chưa lưu**:
